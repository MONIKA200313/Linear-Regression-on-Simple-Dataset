# 📈 Linear Regression on Advertising Dataset

## 📌 Overview
This project builds a Linear Regression model to predict sales based on advertising spend.

---

## 🎯 Objective
To understand how advertising channels affect product sales.

---

## 🛠️ Technologies Used
- Python
- Pandas
- Matplotlib
- Scikit-learn

---

## 📊 Dataset
- TV Advertising
- Radio Advertising
- Newspaper Advertising
- Sales

---

## ⚙️ Workflow
1. Load dataset  
2. Split data  
3. Train model  
4. Predict values  
5. Evaluate performance  
6. Visualize results  

---

## 📐 Model Formula

y = b0 + b1x1 + b2x2 + b3x3

---

## 📉 Output
- MAE (Error)
- R² Score (Accuracy)
- Graph: Actual vs Predicted Sales

---

## ▶️ How to Run

```
pip install -r requirements.txt
cd src
python model.py
```
